2. 使用容器 SKU 创建两个根容器“ChatGPT 厨房”“ChatGPT 储藏室”，以及厨房中的“ChatGPT 行李箱”，明确记录三者的容纳能力。

5. 给这瓶牛奶新增文字笔记“已开封”，再修改为“已开封，剩余800mL”。
